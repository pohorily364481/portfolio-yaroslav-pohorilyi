  • Visual Studio Code

    Microsoft Visual Studio Code is een gratis, krachtige, lichtgewicht code-editor voor Windows, macOS en Linux. Op basis van open source is het zeer aanpasbaar met meer dan 25.000 extensies, voor elke ontwikkelaar en elke programmeertaal. Deze tool biedt behalve standaardfuncties ook wel andere dingen zoals Debug, Terminal, Hulp enzovoort. Dit is maar een kleine rij van functionaliteit. Daarnaast heeft VS Code ingebouwde Git-ondersteuning, waardoor versiebeheer wordt zeer makkelijker

MOGELIJKHEDEN

  • Terminal

    Met Terminal in VS Code kan je paden navigeren, testen uitvoeren en projecten opstarten, geschiedenis van recente command zien en daaruit een command kiezen, met versiebeheer werken, bibliotheken installeren en zelfs fonts binnen VS Code veranderen.

  • Debugger

    Tijdens Debugging zijn er acties beschikbaar zoals: Continue/Pause, Step Over, Step Into, Step Out, Stop. Mogelijkheden die hier aangeboden worden zijn verschillende soorten breakpoints, het inspecteren van variabelen en expressies, waarden van variabelen tijdens debugging veranderen of kopiëren, Debug console REPL en Multi-target debugging.

  • Copilot

    Copilot is een AI-chat waarmee je je code kan reviewen en hulp vragen. Ook bestaat er een Plan-functie waarmee AI genereert volgende stappen die programmeurs kunnen uitvoeren. Mooi is dat Copilot laat je precies zien waar de fouten zijn en je vertelt wat je precies moet doen. In Agent-functie doet Copilot het laatste voor jou.

  • Versiebeheer

    VS Code werkt samen met Git, daarom kan je versiebeheer rechtstreeks via IDE uitvoeren. Hier is het zeer handig. Je krijgt een lijst met alle bestanden en daaruit kies je welke bestanden wil je pushen. Ook wordt de status van synchronisatie weergegeven en je kan de oude versie van een bestand met de nieuwe vergelijken. Als er merge-conflicts ontstaan, wordt dat in twee bestanden gemarkeerd zodat je precies de redenen ziet. Commit History kun je hier ook zien.

  • Figma

    Figma is een platform waarmee ontwikkelaars aan een ontwerp kunnen werken, zowel individuele ontwerpers als teams. Met dit platform kan je prototypen voor websites en applicaties maken. Figma is uitgebreid in mogelijkheden en zeer populair is.

MOGELIJKHEDEN

  • Prototyping

    Figma is bedoeld voor prototyping en daarom is dit een van de belangrijkste functies. Met Figma kan je makkelijk prototypen. Hier kan je interacties, animaties, stromen, beginpunten en interacties maken. De manier van het bouwen van navigatie met Figma is zeer duidelijk. Daarna kies je ook een apparaat waarop een prototype weergegeven wordt.

  • Ontwerpen

    Figma biedt uitgebreide functionaliteit voor het bouwen van ontwerp. Alle elementen worden in lagen weergegeven. Vele stijlen en effecten zijn beschikbaar hier, zelfs texturen en Layout Technieken zoals Grid. Ook de tools, denk aan Pen/Pencil, Slice, Hand-tool, Forms, Tekst. Daarnaast zijn er acties aangeboden waarmee je secties en objecten kan beheren, properties kopiëren en Auto Layout toevoegen.

  • Samenwerken

    Figma biedt ruimte voor samenwerking. Je kan workspace aanmaken en ontwikkelaars toevoegen. Hier is mogelijkheid om real-time tegelijkertijd aan een project werken en deelnemen aan een vergadering met gebruik van FigJam Whiteboard. En gebruikers kunnen rechtstreeks opmerkingen plaatsen op lagen of objecten op het canvas. Er zijn ook dingen als rechtenbeheer en mogelijkheid om bibliotheken te delen binnen een team.

  • Dev Mode

    Dev Mode kan je projecten inspecteren en om te zetten in code, zonder het ontwerpbestand te wijzigen. Met behulp van ingebouwde AI kunnen ontwikkelaars en ontwerpers betere code genereren. En alle wijzigingen kunnen vergeleken worden met overzicht van oude en nieuwe versie van een bestand. Het mooiste is integratie met VS Code en Github, zodat het hele ontwikkelproces handiger wordt.
